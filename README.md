# Royal Equestrian Academy

A premium horse riding club website with royal aesthetics, smooth animations, and spacious layouts.

## Tech Stack

- **Framework:** React 18 (Functional Components)
- **Build:** Vite
- **Styling:** CSS Modules
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Design

- **Style:** Royal, Premium, Elegant
- **Colors:** Forest green primary (#1f3d2b), Gold accent (#d6c3a3), Cream background (#f6f3ee)
- **Typography:** Playfair Display (headings), Inter (body)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```
